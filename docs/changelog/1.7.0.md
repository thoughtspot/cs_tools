### Check out the <span class=fc-green>highlights</span> of our latest CS Tools release!

!!! success ""

    === "Metadata extracts scale to wide tables"
        On large clusters, [`searchable metadata`][cst-tools-searchable-metadata] could time out after 300 seconds.
        The cause was not the size of any one request but the __number__ of them: a single wide table with hundreds
        of columns fanned out into hundreds of `metadata/search` calls.

        The request pattern was redesigned entirely. Identifiers are now batched with a bounded fan-out, so one
        wide table costs a handful of requests and thousands of small objects never become thousands of calls.

    === "Snowflake key-pair authentication"
        Key-pair authentication for the [Snowflake syncer][cst-syncer-snowflake] is fully compatible with current
        `snowflake-sqlalchemy`. Credentials are passed through `connect_args` instead of the connection URL, which
        also means your query tags now actually apply.

        A regression test and a driver-version CI matrix keep it that way.

    === "Reliable installation on corporate networks"
        The installer fetches its updater from the raw content CDN instead of the GitHub API, so shared and
        corporate networks that exhaust the API rate limit can still install and update __CS Tools__.
