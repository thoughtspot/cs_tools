# :octicons-tag-16: v1.6.7 to v1.6.9
## :wrench: &nbsp; Maintenance releases

---

Three small releases between the V2 API release and 1.7.0. No new minimum versions, no breaking changes.

!!! success ""

    === "v1.6.9"
        __July 16, 2026__ &nbsp; [Release notes][gh-release-169]

        - Fixed an inverted retry predicate that caused intermittent command failures. Requests that should have
          been retried were not, and requests that should have failed fast were retried.

    === "v1.6.8"
        __July 2, 2026__ &nbsp; [Release notes][gh-release-168]

        - Added `IsBillable` to the [`searchable ts-ai-stats`][cst-tools-searchable-ai-stats] extract.
        - Fixed internal version reporting.

    === "v1.6.7"
        __March 13, 2026__ &nbsp; [Release notes][gh-release-167]

        - Fixed the `searchable ts-ai-stats` extract for the generally available __TS: AI and BI Stats__ worksheet.
        - Fixed invalid console markup in the Archiver's progress display.
